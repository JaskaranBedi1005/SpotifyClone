# 🎧 Spotify Clone

A simple and responsive clone of the Spotify web player built using **HTML**, **CSS**, and **JavaScript**. This project replicates key UI elements of the original Spotify interface, including a functional music player UI— built from scratch.

## 🔥 Features

- 🎵 Modern Spotify-style UI
- 📱 Fully responsive design
- ⏯️ Play/Pause and seek functionality (static for now)
- 🎨 Clean layout with custom styling
- 🧠 Great for learning DOM manipulation

## 🔗 Live Demo

👉 [Live Demo](https://jaskaranbedi1005.github.io/SpotifyClone/)

## 🛠 Tech Stack

- **HTML** – for page structure  
- **CSS** – for styling and layout  
- **JavaScript** – for interactivity
